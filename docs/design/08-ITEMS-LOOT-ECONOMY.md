# 08 — 道具、掉落、资源与经济系统

## 1. 设计目标

经济系统用于支持战斗决策和长期成长，而不是制造重复刷取。核心资源保持少而清晰：
- Credits：通用货币，用于购买、维修、基础强化。
- Parts：武器与装备改装材料。
- Intel：通过探索和支线获得，用于解锁隐藏任务、商店库存和剧情资料。
- RED Samples：后期稀有资源，用于特殊能力树。

禁止超过 4 种长期货币。

## 2. 战斗消耗品

### 医疗
- 小型绷带：快速恢复少量生命，移动中可用。
- 医疗包：恢复大量生命，使用时间较长，可被打断。
- 肾上腺素：短时间提升移动和近战速度，并减少受击硬直。
- 止血剂：清除持续流血。

### 投掷物
- 破片手雷：标准范围爆炸。
- 冲击手雷：高击退、低致命伤。
- 燃烧瓶：持续燃烧区域。
- 闪光弹：致盲和 AI 混乱。
- 烟雾弹：降低远程命中和视觉感知。
- EMP：干扰机器人、炮塔和电子门。
- 地雷：防守和伏击。
- 遥控炸药：玩家主动引爆。

### 战术工具
- 开锁器：打开部分资源房。
- 黑客模块：破解电子门、炮塔、摄像头。
- 便携护盾：部署短时掩体。
- 自动炮塔：有限弹药、有限持续时间。
- 侦察无人机：短时显示敌人与隐藏物。

## 3. 装备槽

玩家拥有：
- 主武器 ×1
- 副武器 ×1
- 近战 ×1
- 投掷物 ×1
- 战术道具 ×1
- 护甲 ×1
- 被动装备 ×2

剧情后期可解锁额外战术槽，但不增加主武器数量，避免 UI 和操作复杂度失控。

## 4. 护甲

护甲分为轻型、中型、重型。

轻型：高移动、低护甲、闪避恢复快。
中型：综合型。
重型：高减伤、高硬直抗性，但降低冲刺速度和跳跃性能。

护甲属性：`armorValue / poise / movePenalty / explosionResist / fireResist / electricResist / durability`。

## 5. 被动装备示例

- 快速弹匣袋：备用弹药容量 +20%。
- 稳定枪托模块：连续射击后坐增长降低。
- 陶瓷插板：第一发高伤子弹减伤。
- 轻量靴：翻滚恢复缩短。
- 反冲护腕：重型近战后摇降低。
- 拾荒工具：可破坏箱子掉落率提高。
- 急救训练包：医疗道具使用更快。
- 抗爆层：爆炸击飞降低。

## 6. 掉落来源

普通敌人主要掉落弹药、小额 Credits、低概率消耗品。精英敌人掉落高质量武器/部件。Boss 提供唯一奖励或明确解锁。隐藏区域提供稀有配件、Intel 或特殊武器。任务奖励以确定性内容为主，减少纯 RNG。

## 7. 掉落规则

- 玩家当前缺少某种必要弹药时，动态权重轻微提升，但不能保证必掉。
- 生命低于 25% 且连续多场战斗未掉治疗时，医疗掉落权重提高。
- Boss 战前检查点应保证最低可战斗资源。
- 不允许通过反复重载同一箱子刷新稀有掉落。

## 8. 商店

基地商店分：军火商、医疗台、改装台、黑市情报商。

库存根据章节、支线和 Intel 解锁。核心武器类别必须通过正常主线保证玩家可获得，隐藏内容只能提供变体和高级选择，不得造成关键玩法缺失。

## 9. 武器升级

升级不采用无限 +1/+2/+15 模式。每件武器最多 3 个核心强化等级：
- MK I：基础状态。
- MK II：小幅数值改善并开放一个配件槽。
- MK III：开放武器专长选择。

专长示例：
- 霰弹枪：击退型 / 穿甲独头型。
- SMG：极限射速 / 高稳定。
- 狙击枪：穿透型 / 快速拉栓型。

## 10. 经济平衡

玩家完成正常主线应始终能负担至少一套同阶段主流装备。想收集全部武器和最高改装，需要支线与探索，但不得要求无意义刷怪。

目标：普通玩家在主线流程中每 20–35 分钟获得一次明显的新装备或成长选择。
