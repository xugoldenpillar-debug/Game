# 29 — 全项目生产完成清单

> 本清单用于判断“完整游戏”是否真的完成。任何大项未通过，不应把项目描述为完整成品。

## A. 工程
- [ ] 一条命令启动开发环境。
- [ ] typecheck/lint/test/build全部通过。
- [ ] 数据schema校验进入CI。
- [ ] Debug工具可显示碰撞、AI、任务、性能。
- [ ] 生产构建无开发作弊入口。

## B. 玩家
- [ ] 移动、奔跑、蹲伏、跳跃、翻滚稳定。
- [ ] 徒手轻/重/连击可用。
- [ ] 格挡/反击/处决按设计实现。
- [ ] 所有受击、倒地、起身、死亡状态无卡死。
- [ ] 枪械瞄准、射击、换弹、切枪、拾取稳定。

## C. 武器与道具
- [ ] 所有计划武器均有definition。
- [ ] 100武器最终数量经过内容锁定确认。
- [ ] 每个武器大类有独立战斗价值。
- [ ] 配件槽与兼容规则正确。
- [ ] 手雷、燃烧、闪光、烟雾、EMP、地雷等可用。
- [ ] 弹药和掉落不会导致正常流程频繁资源死锁。

## D. AI
- [ ] 40类敌人或最终确认数量均可运行。
- [ ] 近战槽位工作。
- [ ] 掩体/换位工作。
- [ ] 感知和丢失目标逻辑正确。
- [ ] 支援/医疗/工程类AI发挥角色。
- [ ] AI不会频繁卡墙、挤成一团或穿墙射击。

## E. Boss
- [ ] 8章节Boss全部完整。
- [ ] 每个Boss至少2阶段或等价机制变化。
- [ ] Boss前检查点和补给合理。
- [ ] 无无法躲避的无提示高伤。
- [ ] Boss失败后重试快速。

## F. Campaign
- [ ] 8章48主线全部可从头到尾完成。
- [ ] 所有目标/脚本/检查点可重载。
- [ ] 每关至少有独特事件/机制变化。
- [ ] 章节间敌人、空间、剧情节奏明显变化。
- [ ] 完整通关时间达到目标区间或经过重新定义。

## G. 支线/伙伴/基地
- [ ] 6伙伴功能与个人任务完成。
- [ ] 20–30支线或最终锁定数量完成。
- [ ] 基地核心设施可用。
- [ ] 伙伴不会阻断玩家路线。
- [ ] 伙伴剧情状态正确保存。

## H. 成长/经济
- [ ] 4基础技能树完整。
- [ ] RED能力树完整。
- [ ] 商店/改装/武器升级可用。
- [ ] 正常主线不会因经济不足无法装备当前章节合理武器。
- [ ] 洗点可用。

## I. 剧情
- [ ] 主要角色弧线完整。
- [ ] 关键剧情演出和无线电对白完成。
- [ ] Intel可正确收集和查看。
- [ ] 结局条件和最终选择工作。
- [ ] 不存在引用参考作品受版权保护资产的最终内容。

## J. 美术/动画/VFX
- [ ] 玩家动作最终资源完成。
- [ ] 普通敌人资源可读。
- [ ] Boss独特轮廓和阶段视觉完成。
- [ ] 12+场景主题达到目标。
- [ ] 材质命中、枪口、爆炸、火焰、状态效果完整。
- [ ] 低特效模式仍保留战斗可读性。

## K. 音频
- [ ] 每个主要枪械类别有明显声音区别。
- [ ] 近战命中按材质/重量区分。
- [ ] 环境音覆盖所有章节主题。
- [ ] 音乐战斗层级切换正常。
- [ ] 对话/关键提示不会被枪声长期淹没。

## L. UI/UX
- [ ] 主菜单和继续游戏完整。
- [ ] HUD信息不过载。
- [ ] 装备、技能、基地、任务、设置页面完整。
- [ ] 键位提示随绑定更新。
- [ ] 失败/重开/任务完成流程清晰。

## M. 存档
- [ ] 刷新浏览器后进度保持。
- [ ] 检查点可靠。
- [ ] 唯一奖励不可复制。
- [ ] saveVersion迁移有测试。
- [ ] 损坏/缺字段有安全回退。

## N. 模式
- [ ] Campaign。
- [ ] Chapter Replay。
- [ ] Survival。
- [ ] Defense。
- [ ] Boss Rush。
- [ ] Challenge。
- [ ] New Game+（若纳入1.0）。
- [ ] Rogue Operations（若纳入1.0；否则明确标记post-launch）。

## O. 无障碍/设置/本地化
- [ ] 字幕。
- [ ] 音量分类。
- [ ] 键位重绑定。
- [ ] 震屏/闪光强度。
- [ ] 难度。
- [ ] 中英文架构不依赖图片文字。

## P. 性能
- [ ] 标准关稳定达到性能目标。
- [ ] perf_arena压力测试通过。
- [ ] 粒子/弹道/尸体上限有效。
- [ ] 屏幕外AI降频。
- [ ] 内存长时间游玩无明显持续增长。

## Q. 最终回归
- [ ] 至少多轮全新存档从第1关通到结局。
- [ ] 至少一轮Hard通关关键章节。
- [ ] 每个Boss重试/死亡流程测试。
- [ ] 每种武器类别进入实际关卡测试。
- [ ] 主流浏览器smoke test。
- [ ] 发布版本和回滚版本可部署。

## 最终 Definition of Complete

项目只有在“玩家可以打开网页、理解操作、连续进行主线、使用完整战斗与成长系统、可靠保存、最终通关并看到正确结局”，且没有已知阻断级问题时，才可以称为完整版本。
