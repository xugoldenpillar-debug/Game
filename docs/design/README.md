# Design Documentation

This directory contains the game design source of truth for the stickman side-scrolling action project.

## Documents

- `01-GAME-DESIGN-DOCUMENT.md` — overall product vision, pillars, modes, progression, scope
- `02-COMBAT-AND-ACTIONS.md` — movement, melee, defensive actions, hit reactions, finishers
- `03-WEAPONS-AND-ITEMS.md` — melee weapons, firearms, throwable items, gear and weapon stats
- `04-STORY-AND-LEVELS.md` — world premise, chapter structure, mission types and pacing
- `05-ENEMIES-BOSSES-AI.md` — enemy archetypes, AI states, encounter roles and boss principles

## Design principles

1. Combat feel comes before content quantity.
2. Different weapons must change how the player fights, not only damage numbers.
3. Enemy types must differ by behavior and combat role.
4. Environments should participate in combat through hazards, breakables and interaction.
5. Stickman visuals stay readable and simple while animation, physics, sound and effects carry depth.
6. Systems should be data-driven so new weapons, enemies and levels can be added without rewriting core logic.

## Target scope

The long-term target is a complete browser game with a long-form campaign, multiple combat styles, many firearms and melee weapons, bosses, progression, companions, challenges and replayable modes. Development should begin with a strong vertical slice before expanding to the full campaign.
