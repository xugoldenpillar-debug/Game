# 07 — 武器总表与战斗定位

> 目标：正式版约 100 件可用武器。不同武器必须改变战斗方式，而不是只改数值。

## 1. 品质与掉落

品质：普通 / 优良 / 稀有 / 史诗 / 传奇。品质主要决定词条槽与特殊效果，不允许单纯用夸张数值替代玩法差异。

## 11. 弹药类型

`9mm / .45 / magnum / smg / rifle / AP-rifle / shotgun-shell / slug / sniper / heavy / grenade / rocket / fuel / energy`。

不同弹药必须产生资源压力。重武器弹药稀有，不允许玩家长期无脑使用火箭筒清图。

## 12. 武器统一数据字段

`id, displayName, category, subType, rarity, damage, pellets, fireRate, magSize, reserveMax, reloadType, reloadTime, accuracyHip, accuracyAim, recoilX, recoilY, range, falloffStart, falloffEnd, headshotMultiplier, armorPenetration, knockback, stagger, projectileSpeed, penetrationCount, ammoType, moveSpeedMultiplier, equipTime, adsTime, noiseRadius, tags[], attachmentSlots[], specialEffects[]`。

## 13. 设计规则

- 同类别相邻武器至少有 2 项实质行为差异。
- 每个大类至少有 1 件早期、1 件中期、1 件后期武器。
- 至少 25% 武器通过特殊机制而不是 DPS 形成价值。
- 不允许传奇武器全面碾压普通武器；应以独特玩法为主。
- 枪口、弹壳、换弹、后坐、枪声必须按类别区分。
