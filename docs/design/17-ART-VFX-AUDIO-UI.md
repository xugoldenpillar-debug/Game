# 17 — 美术、特效、音频与 UI 制作规范

## 1. 总体美术方向

核心视觉：高对比 2D 火柴人 + 半写实/图形化城市环境 + 强烈战斗特效。角色轮廓必须在复杂背景上始终可读。

美术资源优先级：动作可读性 > 武器辨识 > 战斗反馈 > 场景层次 > 装饰细节。

## 2. 角色

普通人形共用统一骨架。通过：头部轮廓、服装块面、背包、护甲、武器、阵营色、体型比例区分。

角色至少需要：
- 正常状态
- 受伤状态
- 护甲破损
- 燃烧/电击等状态视觉
- 死亡/Ragdoll 表现

Boss 必须有独特 silhouette，远距离也能分辨。

## 3. 武器美术

100 件武器不要求 100 套完全不同动画，但每件武器图形必须具备可辨识轮廓。每个枪械类别至少有独立：持枪姿势、枪口位置、弹壳方向、换弹动作差异、后坐幅度。

## 4. 场景主题

正式版至少 12 套主题：
1. 城市街区
2. 商店/住宅
3. 停车场
4. 地铁
5. 高速公路
6. 仓库/工业区
7. 军事检查站
8. NOVA实验室
9. 黑帮城区/酒吧/赌场
10. 反抗军基地
11. 战争前线
12. NOVA Tower

每套包含背景层、中景、可交互层、前景遮挡层、光照/天气变体、破坏件。

## 5. VFX 分级

### 轻反馈
手枪枪口、轻拳命中、小火花、灰尘。

### 中反馈
步枪/霰弹、重击、护甲破裂、玻璃破碎。

### 重反馈
爆炸、火箭、Boss砸地、车辆爆炸、建筑坍塌。

任何效果不得长时间遮挡玩家角色、敌人危险前摇或准星。

## 6. 命中特效

根据材质：肉体/普通角色、金属护甲、盾牌、机器人、木头、玻璃、混凝土、车辆分别有不同粒子和音效。

重击应组合：Hit Stop + 局部粒子 + 击退 + 音效 + 可选轻震屏。

## 7. 枪口与弹道

枪口焰按口径分等级。普通弹道可使用 tracer 概率表现，而不是每颗子弹都亮线。狙击/重武器可更明确。

## 8. 屏幕震动

轻：2–4 px 等效幅度；中：5–8；重：9–14（实际依据分辨率适配）。不得连续叠加失控。设置允许 0/25/50/75/100%。

## 9. 音频分类

Bus：Master / Music / SFX / Weapons / Voice / UI / Ambience。

枪械音频至少包括：开火近景、远景尾音、机械动作、换弹、空仓、弹壳。相同类别可共享部分素材，但最终不能所有枪听起来一样。

## 10. 动态音乐

音乐至少有 Explore / Combat / HighIntensity / Boss / Story 五种状态。进入战斗逐层增加，不应每遇一只敌人重新从头播放。

## 11. 环境音

街区：风、警报、远处枪声、火焰。
地铁：混响、滴水、电力声。
实验室：设备嗡鸣、广播、警报。
战争区：远方爆炸、直升机、无线电。

## 12. UI 风格

低装饰、高可读。主HUD只显示：生命/护甲、当前武器、弹药、投掷物、特殊能力、当前目标。Boss 出现时显示专属Boss血条。

## 13. 武器 UI

武器信息：名称、图标、类别、当前弹匣/备用弹药、射击模式。地面拾取对比只显示关键差异，避免覆盖屏幕的大型RPG面板。

## 14. 菜单

主菜单：继续、新游戏、章节/任务、装备、技能、基地、挑战、设置。

装备界面提供武器预览、核心属性、配件槽和特殊效果。技能页按 4 基础树 + RED 树。

## 15. 字幕与叙事

字幕位置避开战斗HUD，可选背景板。无线电对话不应锁死玩家；重要剧情才进入不可操作或半可操作演出。

## 16. 素材命名

`char_player_idle_01`、`enemy_nova_rifleman_body_a`、`wpn_rifle_carbine_a`、`vfx_hit_metal_small`、`sfx_wpn_shotgun_pump_fire_01`、`tile_city_concrete_wall_a`。

## 17. 导出规范

- 角色/武器原图保留源文件与导出文件。
- 游戏内 sprite/atlas 不覆盖源文件。
- 透明边界尽量紧凑。
- 纹理尺寸采用合理上限，不为小型2D元素导出超大贴图。
- 所有资源引用使用逻辑 key，不硬编码磁盘路径。

## 18. 验收

- 1080p 下玩家、敌人、危险投射物清晰可读。
- 低特效设置仍保留必要战斗信息。
- 同时发生多个爆炸时不会完全遮挡战场。
- 音量平衡下枪声有冲击但不长期压过对白和关键提示。
