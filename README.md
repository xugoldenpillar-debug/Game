# Game

Private repository for the stickman side-scrolling action game project.

## Project direction

A browser-based 2D stickman action game inspired by the pacing and accessibility of classic side-scrolling stickman combat games, expanded with deeper melee combat, firearms, items, long-form story chapters, enemy AI, bosses, progression, destructible environments, and reusable data-driven content.

## Documentation

Design documents live under [`docs/design/`](docs/design/README.md).

## Current phase

Pre-production / game design. The immediate goal is to lock the combat feel, action set, weapons, enemy behaviors, story/level structure, and technical content schema before full production.
